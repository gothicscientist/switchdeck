# Switchyard

A custom mechanical keyboard builder. Answer a short finder quiz or pick parts slot by slot (case, PCB, plate, switches, stabilizers, keycaps, extras), with compatibility checks, price totals and a sound/feel estimate.

Single static page: `index.html`, plain HTML/CSS/JS, no build step. Open it in a browser to run locally.

Deployed with GitHub Pages via `.github/workflows/pages.yml` (Settings → Pages → Source: GitHub Actions).

Prices and some specs in the catalog are approximate. Check them with sellers.
